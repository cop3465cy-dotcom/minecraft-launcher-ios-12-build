# Contributing

Thanks for helping improve Blockside. Before opening a pull request:

1. Search existing issues and pull requests for the same report or change.
2. Keep changes compatible with the iOS 12.2 deployment target and the legacy Pojav engine unless the proposal explicitly changes that support.
3. Preserve upstream copyright notices and GPL-3.0 obligations when editing `Engine/PojavLegacy/`.
4. Do not commit Apple signing certificates, provisioning profiles, private device identifiers, Minecraft account data, access tokens, or downloaded game assets.
5. Describe affected files, user-visible changes, device/OS context, and any manual verification performed.

For bug reports, include the device model, iOS version, Blockside build/tag, selected Minecraft version, and a redacted log excerpt. Remove usernames, tokens, world names, and server addresses before sharing logs.
