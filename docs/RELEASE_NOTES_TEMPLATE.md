## Blockside {{VERSION}}

An independent iOS launcher interface built on the PojavLauncher iOS v2.2 engine.

### Install

Download `Blockside-Java-Edition.ipa` and install it using a compatible sideloading app. See the [iPhone/iPad install guide](https://github.com/cop3465cy-dotcom/minecraft-launcher-ios-12-build/blob/master/docs/INSTALL.md).

### Compatibility

- iOS/iPadOS 12.2 or later.
- Java 8 and Java 17 runtimes bundled. Minecraft 1.20.5+ needs Java 21 and is not supported by this build.
- JIT is required for usable game performance.
- No Minecraft game files or account are included.
