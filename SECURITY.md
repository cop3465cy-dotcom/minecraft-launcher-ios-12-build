# Security policy

Do not post credentials, Microsoft account data, private world saves, provisioning profiles, signing keys, or unredacted logs in public issues.

For a security-sensitive report, use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise, contact the repository owner privately through GitHub before publishing details. Do not include account passwords or tokens in a report.

Only install project builds from this repository's GitHub Actions or Releases. Verify release checksums when provided. Third-party signing services and profiles are outside this project; use them only if you understand and trust their operators.
